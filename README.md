# AVP-IR-Wake-Code
## Revealing Imaging Characteristics of Thermal Wakes from Underwater Vehicles Without Cooling-Water Discharge
Our supplementary video (Supplementary_Video_1.avi) provides a representative infrared recording captured during rainfall. To better visualize the transient environmental interference, users can process the video using the frame_diff.py script provided in our code repository. By applying an appropriate frame-difference interval (e.g., 15 frames) to amplify the temporal discrepancies, the generated pseudo-color maps clearly reveal the impact points of raindrops and the resulting spreading ripples on the water surface. This highlights the complex dynamic background clutter that thermal wake detection algorithms must overcome in real-world scenarios.
